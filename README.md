# Servitel — buscador de productos

Página para identificar productos de menaje a partir de una foto, desde el móvil.

Todo el cálculo ocurre **en el propio teléfono**: descarga el modelo CLIP y el índice
de productos una vez, y a partir de ahí compara la foto sin enviar nada a ningún
servidor.

Este repositorio contiene solo la página publicada. Las herramientas que generan el
índice a partir de los catálogos PDF no forman parte de él.
